s2-field-ndvi / findings brief / every number measured, none modeled

The 2020 derecho, measured field by field.

On August 10, 2020, a land hurricane crossed Iowa with winds past 100 mph. This pipeline turns raw Sentinel-2 pixels into a damage score for every USDA field boundary it touched — from public data, on open-source Spark + Sedona + Iceberg, for a few dollars of compute.

01 / WHY

The question nobody could answer quickly

After the storm, damage assessment took weeks and a GIS desk: which fields lost canopy, and how badly? Insurers, agronomists, and USDA all needed the same number and none had it. The satellite data to answer it was public the whole time — what was missing was a pipeline that could hold every field in the state and stand behind every value it reports.

The hard part is not computing vegetation greenness. It is that August 2020 was also a flash drought — Drought Monitor coverage nearly doubled inside the study window — so any honest damage estimate has to subtract what the drought was doing to fields the wind never touched.

02 / HOW

Three moves, all pre-registered

Thresholds were fixed in config.yml before any result was computed, and never tuned against the outcome.

STEP 1

Pixels, masked per pixel

Sentinel-2 scenes before (Aug 4) and after (Aug 19) the storm. Cloud and shadow pixels removed with the SCL classification layer; NDVI computed on what survives.

STEP 2

Fields, not pixels

One zonal pass scores all 7,226 USDA field boundaries in the demo county — mean NDVI plus valid_frac, the share of each field that survived masking.

STEP 3

Subtract the drought

Each storm-hit corn field is compared to corn fields outside every wind polygon at matched latitude (≥5 controls). What remains is the storm.

04 / WHEN WE SCALED IT

Seventeen times bigger — and the gate fired

The event study re-runs unchanged against the statewide warehouse: six Sentinel-2 tiles, roughly half of Iowa, 13,580 matched treated corn fields instead of 785. The pre-registered monotonicity check failed: the 80‑99 mph band came out worse than 100+, by about nine standard errors. That is not noise, and the honest move is to show it.

The forensics cleared the data first: the Benton County subset of the statewide warehouse reproduces the county table above exactly, to four decimals, from a warehouse computed on entirely different infrastructure. What broke was a design assumption. Controls are matched on latitude alone, which cancels the concurrent flash drought inside one county — but the drought was worse in western Iowa, the 80‑99 band reaches far west (its estimate runs -0.141 in its western third against -0.040 in its eastern third), and the 100+ core near Cedar Rapids has no western fields at all. The middle band was absorbing uncontrolled drought. Add longitude to the match and the dose-response returns, at magnitudes consistent with the county study. The pre-registered analysis stays the result of record; the fix is labeled post-hoc, dated, and reported next to it.

The identification held inside one county. It did not survive the state — and a pre-registered gate, not a reviewer, is what said so.

05 / WHAT WE REFUSE TO SHOW

A map that admits what it cannot see

Fields render grey when cloud masking leaves less than half the field observable on either date. No gap-filling, no max-value compositing — picking the healthiest-looking date would bias measured damage toward zero. Storms make clouds, so the attrition is real and it is reported:

Optical NDVI also understates lodging — flattened corn stays green for weeks. Every estimate on this page is therefore a floor, not a point estimate.

07 / HOW IT RUNS

One container, laptop to cluster

The pipeline is Apache Spark 3.5 + Apache Sedona 1.9.1 + Apache Iceberg, and the same image runs every tier below — spark-submit local[4] on a laptop, a real Kubernetes cluster (driver and executor pods, verified end to end, both native submit and the Spark Operator CRD), and EC2/EKS in us-west-2, in-region with the Sentinel-2 archive. Every run is incremental by construction: re-query, diff against the Iceberg manifest, process only the delta.

08 / RUN IT YOURSELF

Reproduce this for $0

The demo tier runs end to end on a laptop in about seven minutes, no cloud account, against the public Sentinel-2 archive. Each run ends with a Great Expectations gate; any failure stops the pipeline.

git clone https://github.com/owensross27/s2-field-ndvi
cd s2-field-ndvi && make setup && make data
make pipeline     # 01 fields → 02 scenes → 03 ndvi → 04 publish → 05 dq gate
make web-serve    # this page + the map at localhost:8137
